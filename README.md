# Balaji Digital Seva

Digital VCard / service website for Balaji Digital Seva, Deepak Mishra (VLE), Bhatapara.

## Included
- Mobile-first attractive VCard layout
- English / Hindi toggle
- Service search and categories
- Service-wise available work
- Required Documents shown only where documents are actually relevant
- WhatsApp enquiry text changes automatically when documents are not required
- Call, WhatsApp, Instagram, Save Contact and Share
- Sunday to Saturday, 10:00 AM to 10:00 PM timing
- Gallery placeholder
- Google Maps directions using the center address
- Dark mode
- PWA / Add to Home Screen support

## Important
For the install prompt and PWA offline support, upload the project to HTTPS hosting such as GitHub Pages. Opening `index.html` directly from a computer will not show the browser's install prompt.

Replace `assets/logo.svg` later if you want to use your final logo file, keeping the same filename.

## Install button
The visible 'Add Balaji Digital Seva to Home Screen' card uses the browser's PWA install prompt when available. On browsers that don't expose the prompt, it gives manual Android/iPhone instructions.
